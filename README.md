# 🎵 Spotify Clone  

This is my **first dynamic project** — a Spotify Clone built using **HTML, CSS, and JavaScript**.  
It includes a fully functional **playbar**, essential **UI/UX elements**, and a **responsive design** that works across devices.  

---

## ⚡ Features  
- ✅ Functional **Playbar** (Play/Pause/Next/Previous)  
- ✅ Clean and minimal **UI/UX**  
- ✅ **Responsive design** for all screen sizes  
- ✅ Built with **HTML, CSS, JavaScript** only  

---

## 🛠️ Tech Stack  
- **HTML5** – Structure  
- **CSS3** – Styling & Layout  
- **JavaScript (ES6)*
* – Interactivity
